# Exemplos de Documentação Gerada

Este diretório reúne as saídas de documentação avaliadas no estudo comparativo do
Trabalho de Conclusão de Curso *"Clarity: Sistema Inteligente para Geração Automatizada
de Documentação Técnica em Projetos de Programação"* (IFPB, Campus Campina Grande, 2026),
descrito no Capítulo 5 da monografia.

Para cada repositório experimental são disponibilizadas as saídas geradas por duas
ferramentas:

- `README-CLARITY.md` — documentação gerada pelo **Clarity**;
- `README-AI.md` — documentação gerada pela ferramenta de referência **README-AI**.

## Repositórios avaliados

Os três projetos pertencem ao acervo de sistemas internos da Superintendência de Trânsito
e Transportes Públicos de Campina Grande (STTP):

| Pasta             | Projeto                      | Stack                     |
|-------------------|------------------------------|---------------------------|
| `nutri-sttp/`     | Nutri-STTP                   | JavaScript, React + Vite  |
| `transitolandia/` | Transitolândia Admin         | JavaScript, React + Vite  |
| `siga/`           | SIGA Talonário Eletrônico    | TypeScript, Next.js       |

## Observação

Os arquivos são reproduzidos exatamente como produzidos por cada ferramenta, sem edição
manual, para fins de rastreabilidade e de verificação independente das notas atribuídas na
avaliação por rubrica.
